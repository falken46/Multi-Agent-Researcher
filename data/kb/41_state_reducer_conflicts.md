# LangGraph 状态 Reducer、覆盖更新与并发冲突

## Reducer 解决的不是字段定义问题

TypedDict 负责说明状态有哪些字段以及字段类型，但它本身不决定两个节点同时更新同一字段时如何合并。Reducer 处理的是更新语义：新值覆盖旧值、列表追加、字典合并，还是由自定义函数消解冲突。把 schema 与 reducer 混为一谈，会让开发者以为声明了 `list[str]` 就天然具备追加行为，实际运行时却可能只保留最后一次写入。

## 默认覆盖适合单一所有者字段

`topic`、`final_report`、`quality_score` 这类字段通常只有一个明确节点负责写入，默认覆盖最容易理解。Planner 不应修改最终报告，Writer 也不应改写原始主题。字段所有者清晰时，不使用 reducer 反而更安全，因为重复写入会直接暴露设计冲突，而不是被自动合并掩盖。

## 列表追加适合独立事件而非当前快照

错误历史、消息序列或工具调用记录常适合追加 reducer。它们表达“发生过什么”，不是“当前值是什么”。但 `missing_aspects` 表示 Critic 当前要求补查的方向，如果无条件追加，旧缺口会在返工完成后仍然存在，Researcher 可能重复查询。因此相同的 `list` 类型可能需要完全不同的更新规则。

## 字典合并需要定义键冲突

Researcher 以子问题为键写入 `research_results`，多个并发任务可以分别返回一个小字典，再由 reducer 合并。真正困难的是两个任务写入同一个键：是保留先完成的结果、后完成的结果，还是把文本拼接？如果没有明确规则，并发完成顺序会改变最终状态。项目当前由一个 Researcher 节点在内部 gather 后统一返回字典，避免让图层直接处理这类冲突。

## 并发节点与节点内部并发是两层概念

StateGraph 可以让多个节点并行，Researcher 也可以在单个节点内部并发处理多个子问题。前者需要 reducer 合并多个节点更新，后者可以由节点在返回前自行整理结果。本项目选择后者，是因为所有子问题属于同一个角色职责，异常隔离、排序和 citation 合并都能在 Researcher 内集中处理。

## 覆盖更新不等于丢失历史

当前质量分 `quality_score` 应覆盖为最新值，同时 `quality_history` 追加保存历史。若只保留历史而没有当前值，路由每次都要取列表末项；若只覆盖当前值，又无法判断评分是否停滞。两个字段看似重复，实际分别服务快速路由和趋势判断。

## Reducer 不能替代幂等设计

Checkpoint 恢复后某个节点可能再次执行。如果节点重复调用外部服务或重复追加同一条事件，仅依赖 reducer 无法自动判断哪一条是重复数据。幂等键、稳定 chunk ID、已经完成的样本记录和恢复协议仍需单独设计。Reducer 只决定“两个更新怎样合并”，不判断“这个更新是否应该再次发生”。

## 删除语义必须显式

字典合并 reducer 往往只会新增或覆盖键，无法表达删除。返工完成后清空 `missing_aspects`、重新开始任务时清空旧报告，都需要节点明确返回空值或专用删除标记。若把空列表解释成“不更新”，状态就永远无法被清空；若把缺失字段解释成清空，又会破坏部分更新。因此协议必须区分“未提供”和“明确置空”。

## 测试应构造冲突而不是只测正常路径

Reducer 测试不能只验证一个节点写一次字段。高价值用例包括：两个更新写不同字典键、两个更新写相同键、列表字段清空、恢复后重复提交、异常结果与成功结果同时返回。断言最终状态的同时，还要检查顺序是否由明确规则决定，而不是碰巧符合当前调度。

## 与普通共享内存的区别

LangGraph 状态更新更接近事件驱动的数据流，不是多个线程随意修改同一个 Python 对象。节点返回增量，由框架按 schema 应用。这个边界让 checkpoint 和回放成为可能，也要求开发者提前声明更新语义。直接在节点内部原地修改嵌套对象可能绕过预期合并规则，应优先复制后返回。

## 选择 reducer 的判断顺序

可以依次问四个问题：字段是否有唯一写入者；字段表达当前快照还是历史；相同键并发出现时谁获胜；字段是否需要删除或清空。只有回答清楚后再选择覆盖、追加或自定义 reducer。为了展示框架能力而给所有字段都加 reducer，只会增加难以解释的隐式行为。

## 本项目的边界

当前图主要串行经过 Planner、Researcher、Critic、Writer，真正并发发生在 Researcher 节点内部，因此大部分状态字段采用明确覆盖或节点内合并已经足够。如果未来把多个专家 Agent 作为并行图节点，就需要为研究结果、引用和错误字段正式声明 reducer，并补充冲突与恢复测试。
